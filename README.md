# Cartonagem Circulus — Landing Page

Landing page institucional da **Cartonagem Circulus**, empresa do setor de cartonagem e embalagens. Site de página única (one-page) com seções de apresentação, vídeo, tecnologia, certificações, diferenciais, equipe, segmentos atendidos, compliance, localização e contato.

🔗 **Demo:** https://v0-cartonagem-circulu-s-landing-pag.vercel.app

## 🧰 Tecnologias

- [Next.js](https://nextjs.org/) (App Router)
- React 19 + TypeScript
- Tailwind CSS

## ▶️ Rodando localmente

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # build de produção
```

## 📁 Estrutura

- `app/` — rotas e layout (App Router)
- `components/` — seções da página e componentes de UI (`sections/`, `ui/`)
- `hooks/`, `lib/` — hooks e utilitários
- `public/` — imagens e assets estáticos
- `styles/` — estilos globais
